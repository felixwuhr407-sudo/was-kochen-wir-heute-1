What Should We Cook Today?
Welcome to What Should We Cook Today?
Do you know that feeling? You want to cook something, but you have no idea what to make. That is exactly what this website is designed to help with!
What Should We Cook Today? is a self-developed cooking app designed to inspire people with new meal ideas and make choosing what to cook a little easier.
The Idea Behind the Project
I wanted to create my own website focused on cooking, where people can find inspiration for their next meal.
This project was developed step by step with the help of ChatGPT.
How Was the Website Built?
The website uses:
HTML for the structure
CSS for the design
JavaScript for functionality and interactions
The project was developed using Visual Studio Code.
The Goal
The idea is simple: spend less time deciding and discover more cooking ideas!
I want to keep improving the website step by step and make it accessible to more people.
Looking Ahead
The project can continue to grow with new ideas and features.
Thanks for Visiting!
Thank you for checking out my project. Have fun exploring What Should We Cook Today?
